Experiment drivers for the Rex paper.

Run all scripts from this directory (so that `samplers/` is importable):

```bash
cd image-experiments
python scripts/celeba.py --help
```

See the top-level [README](../README.md) for usage examples and the mapping
between scripts and paper sections.

The diffusion-model baseline scaffolding (BDIA / EDICT / O-BELM / DDIM) is
adapted from <https://github.com/zituitui/BELM>.
